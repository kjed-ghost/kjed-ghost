# Personal Portfolio Website

A stunning, modern, and highly responsive personal portfolio website built for Kaushik John Emmanuel Daniel (KJED).

## Tech Stack

- **Framework:** [Next.js 15.1 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)

## Features

- **Neon Aesthetic:** High-ticket, modern dark mode design with neon glow effects.
- **Responsive Design:** Optimized for all devices from mobile to ultra-wide monitors.
- **Service Sections:** Dedicated layouts for Full-Stack Development, WordPress Specialization, and AI Integration.
- **Social Connect:** Custom-designed cards for professional platforms (GitHub, Upwork, Freelancer, Reddit, Discord).
- **Contact System:** Integrated contact form and direct contact information.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Customization

- **Profile Image:** Replace `public/profile.jpg` with your own photo.
- **Logo:** Replace `public/logo.png` with your brand logo.
- **Information:** Update the text in `src/app/page.tsx` and `src/app/contact/page.tsx` to reflect your specific details and links.
